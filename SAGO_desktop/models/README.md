# SAM2 model weights

SAGO Desktop 1.1 supports SAM2 point and box prompts only.

Place the original `sam2_hiera_large.pt` here, or select a checkpoint in Preferences or with `sago --checkpoint path/to/sam2_hiera_large.pt`.

Obtain the checkpoint from the official [SAM2 repository](https://github.com/facebookresearch/sam2). The full Debian package bundles this checkpoint. Model weights are not included in Git source distributions; their original license terms apply.
