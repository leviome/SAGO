模型加载

SAGO 操作指南

  1. 加载本机已重建的 3DGS PLY 或训练输出目录。
  2. 拖动旋转，Shift 拖动平移，滚轮缩放。松开鼠标后更新画面。可填写原场景的上方向，或点击“三点确定地面”标定向上方向。
  3. 按 M 或勾选“进入分割提示”后，左键添加前景点，右键添加背景点，也可以拖框；取消勾选恢复相机操作。
  4. 三个模型均支持文本、点或框提示；SAM2 使用 GroundingDINO 将文本定位为检测框。添加点、框或文本提示后自动分割，继续调整提示会自动更新；选择目标实例的候选 mask。
  5. 点击“三维分割”（快捷键 P）排除物体背后的背景。
  6. 旋转检查结果，点击“增加ID”保存并隐藏当前物体，自动进入下一轮分割提示；可在物体列表中选择或显示已保存物体，完成后点击“保存分割结果”写入 SAGO_knowledge.json；可导出 PLY、逐高斯布尔 mask 或图像。

切换模型时立即加载，并单独显示加载用时；默认使用 SAM2，首次勾选“进入分割提示”时加载。关闭网页不会结束 Python 服务。当前为本机共享工作空间，请仅使用一个操作页面。
